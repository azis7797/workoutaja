# 🏋️‍♂️ workoutaja
workoutaja adalah aplikasi web sederhana yang membantu Anda merencanakan dan melacak rutinitas latihan harian. Dibuat dengan HTML dan CSS, aplikasi ini dirancang untuk memberikan pengalaman pengguna yang intuitif dan responsif.

# 🚀 Fitur
Antarmuka Pengguna yang Bersih: Desain minimalis yang memudahkan navigasi dan penggunaan.

Responsif: Tampilan yang optimal di berbagai perangkat, baik desktop maupun mobile.

Struktur Sederhana: Mudah dipahami dan dikembangkan lebih lanjut.

# 📸 Pratinjau

Catatan: Gambar di atas adalah ilustrasi antarmuka aplikasi.

# 🛠️ Teknologi yang Digunakan
HTML5: Struktur halaman web.

CSS3: Gaya dan tata letak.
